# Dials

**업무 담당자와 내선번호를 쉽고 빠르게 찾는 웹 전화번호부**

🌐 [Dials 열기](https://bak2ya.github.io/Dials/)

<img src="./icons/icon-192.png" alt="Dials 아이콘" width="96" height="96">

Dials는 교직원 이름을 마스킹한 공개 전화번호부를 기본으로 표시합니다. 기타시설 연락처는 승인된 시설명·담당자 실명·전화번호가 그대로 표시될 수 있습니다. 별도 인증 없이 소속·직위·공개 담당업무·내선번호를 검색할 수 있습니다.

## 주요 기능

- 소속별 업무용 연락처 검색과 내선 통화 연결
- 업무분장 검색 (`교원 인사`, `교원인사`, `교원`) 및 관련 담당자 표시
- 카드의 **ⓘ** 버튼으로 해당 담당자의 업무분장 상세 확인
- 우측 `···` 메뉴에서 선택적으로 상세 연락처 파일 연결
- 라이트 / 다크 / 블랙(OLED) / 시스템 화면 모드
- 휴대폰·태블릿·데스크톱 지원 및 홈 화면에 추가

## 공개 데이터와 보안

- 공개 전화번호부는 HJU Phonebook 관리자가 학교의 공개 승인 범위에 맞춰 별도로 생성합니다.
- 공개 파일 `public-directory.json`은 GitHub Pages를 통해 **누구나 다운로드할 수 있는 자료**입니다. 교직원 이름은 성+○○로 마스킹되지만, 기타시설 담당자 실명과 휴대전화는 원문으로 포함될 수 있습니다. 소속·직위·업무와 번호의 결합으로 개인을 알아볼 수 있으므로 배포 전에 공개 범위를 반드시 확인해야 합니다.
- 상세 연락처는 별도로 배포되는 암호화 `.dials` 파일을 연결하고 비밀번호로 해제합니다. 브라우저에 비밀번호를 영구 저장하지 않으며, 잠금 시 공개 모드로 돌아옵니다.
- 기타시설 담당자의 인터넷 실명/개인번호 공개에는 적법한 근거 및 승인이 필요합니다.
- GitHub 업로드용 ZIP의 `public-directory.json`에는 실제 인물이 없습니다. 운영용 공개 연락처는 관리 프로그램에서 검토·생성한 데이터로 교체해야 합니다.

## 연동

업무용 연락처는 Windows 관리자용 **HJU Phonebook**에서 관리합니다. HJU Phonebook이 생성한 공개 JSON을 이 저장소의 `public-directory.json`에 게시하면 Dials가 자동으로 불러옵니다. 암호화 상세 연락처 파일은 GitHub에 게시하지 않습니다.
